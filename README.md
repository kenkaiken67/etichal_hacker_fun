# 🚀 Web-Based Ethical Hacker Terminal

Selamat datang di repositori **Web-Based Ethical Hacker Terminal**! 
Ini adalah sebuah website portofolio interaktif bergaya *Command Line Interface* (CLI) yang dirancang khusus untuk menampilkan profil dan keahlian di bidang *Cyber Security* dan *Software Engineering*.

## 📖 Deskripsi Singkat
Project ini bukan sekadar website statis biasa, melainkan simulasi lingkungan Linux/Web-Environment. Pengunjung dapat berinteraksi langsung dengan website menggunakan perintah-perintah teks (seperti di terminal sungguhan) untuk melihat informasi, melakukan simulasi *scanning*, hingga mengenkripsi teks.

## ✨ Fitur Utama
- **Interaksi CLI (Command Line Interface):** Pengalaman navigasi menggunakan teks dan *keyboard*, bukan *mouse*.
- **Fungsi Kriptografi Nyata:** Fitur `encode` dan `decode` teks ke format Base64 yang berfungsi secara *real-time*.
- **Simulasi Tools Keamanan:** Simulasi respons alat *penetration testing* populer seperti `dirb` (Directory Scanner) dan `jtr` (John The Ripper).
- **Command History:** Mendukung tombol **Panah Atas (↑)** dan **Panah Bawah (↓)** untuk memanggil riwayat perintah yang sudah diketik sebelumnya.
- **Matrix Digital Rain:** Animasi latar belakang hujan kode (HTML5 Canvas) dipadukan dengan efek *scanline* monitor CRT jadul.

## 🛠️ Teknologi yang Digunakan (Tech Stack)
Project ini dibangun 100% menggunakan teknologi web murni tanpa *library* eksternal:
- **HTML5** untuk struktur dokumen.
- **CSS3** untuk desain antarmuka, *layouting*, dan efek visual (Glow, CRT scanlines).
- **Vanilla JavaScript** untuk logika pemrosesan perintah, DOM *manipulation*, dan animasi Canvas (Matrix Rain).
